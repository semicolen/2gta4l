# SM-T505 mobile data status

On 13 October 2026, the user inserted their phone SIM into the tablet and
confirmed that mobile data works on the installed postmarketOS system.
LTE/mobile data is now recorded as **working, user-confirmed**.

Earlier automated checks established modem discovery through ModemManager,
QRTR services and the IPA/RMNET interfaces. The earlier experimental SIM had
no data plan, so those checks could not establish mobile internet connectivity.

The new confirmation applies to the installed system using kernel #9. It is
not a fresh-install test of the six r5 UI candidates. Calls, SMS, mobile data
reconnection after reboot, sustained throughput and the radio access technology
of this particular session have not been recorded by this test.
